# What's new in Skovern

Each release lists what changed, in plain words. The app shows the newest entry when it offers
an update. The release workflow refuses a version with no entry here.

## v0.1.2 — 2026-10-27

- Drop-down menus match your theme now. In dark mode, the list under Pick a brain is dark too, with easy-to-read words, instead of a pale grey box.
- Those menus open as a neat little card below the box, with a check next to the one you picked.

## v0.1.1 — 2026-10-26

- Skovern has a fresh new look: a clean sidebar with icons, rounded lists, and chat bubbles that feel like your phone.
- Dark mode: if your computer is set to dark, Skovern follows it.
- Skovern has its own icon now, in your taskbar, Start menu, and tray.
- Small windows work better: the sidebar shrinks to icons so your chat gets the room.

## v0.1.0 — 2026-10-25

- Skovern can now update itself. When a new version is out, a small note asks if you want it.
- Settings has a new Updates section: see which version you have, check for a new one, or turn off automatic checks.
- Every update check shows up on your Receipts page, like everything else that leaves your computer.
